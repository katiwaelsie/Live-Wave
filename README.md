# LiveConcerts – Online Livestreaming Platform

LiveConcerts is a web-based platform designed to connect event creators with audiences through live online broadcasts. It allows creators to organise events and livestream concerts, performances and other entertainment events, while viewers can watch events online.

### Features
- Creator dashboard for managing events.
- Event creation and management.
- Live video broadcasting using Agora RTC.
- Camera access for live streaming.
- Viewer interface for watching live events.
- Supabase integration for authentication and database management.
- Event access and ticket management foundation.
- Replay functionality for watching completed events, where available.

### Technologies Used
- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- Agora RTC

### Project Goal
To make live entertainment more accessible by allowing event organisers to reach audiences online and giving viewers the opportunity to enjoy events remotely.

**Project Status:** Under development. M-Pesa payment integration is planned.
